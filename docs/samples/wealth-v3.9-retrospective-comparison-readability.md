# 财富 v3.9 回顾与年度比较可读性验收

> 范围：财富通俗版的“去年回看”和“年度比较”。
> 版本：`wealth-plain-v3.9`；计算版本、表达策略和标题规划版本不变。
> 样本：固定开发命盘 R01–R12，不代表真人经历准确率。

## 本次改动

- 去年回看不再拼接“这方面、它主要关系到、可能有进展”等无明确对象的句子。
- 主判断和次判断都明确写出要核对的资金问题；隐性影响只保留独立核对角度，不重复上一条判断。
- 混合状态改成两种具体可能，不再把两个规则标签直接用“和”连接。
- 年度比较不再显示“有利条件、支撑增强、相对位置、整体信号”等内部术语。
- 每段年度比较明确写出比较年份、变化对象和下一步行动。
- 相邻两段行动带上目标年份，避免同一份报告出现完全相同的句子。

## 引擎实际输出节选

### R01 去年回看

- 主判断：回看2025年，先核对投入增加后，实际进账有没有跟着提高。
- 命盘提示，投入后实际进账提高的信号较明显。
- 次判断：再回看并核对进账增加后，实际留下的钱有没有变多。
- 有些时候能多留下一点钱，有些时候进账增加了，结余却没有跟着增加。
- 隐性影响：还要回看共同用钱带来的责任是否影响实际结余。
- 如果去年增加投入后，实际进账有所提高，今年再看这种情况能否延续。

### R03 混合到账判断

- 主判断：回看2025年，先核对预计进账与实际到账是否一致。
- 命盘提示，有些预计的钱能按时到账，也可能出现延期或金额变化。
- 如果去年有些预计的钱按时到账，也有些到账延期或金额有变化，今年安排时要把两种情况都算进去。

### R04 未变化年份

- 与2026年相比，2027年预计的钱是否按时到账，以及延期的可能，都没有明显变化。
- 2027年继续按实际到账时间安排支出。

### R06 有变化年份

- 与2026年相比，2027年进账保持连续的迹象更明显。
- 2027年按时到账的迹象减弱。
- 2027年资金责任容易分清的迹象仍然存在，但额外责任和开销增加的风险也没有消失。
- 2027年实际结余增加的迹象比上年多了一些，但仍不明显。
- 2027年先按进账是否持续决定长期支出。

## 自动验收规则

R01–R12 的最终可见文案会拒绝以下正文表达：

```text
这方面
它主要关系到
有利条件
需要留意的限制
条件的组合
本身的倾向
相对位置
这一方向
不必另起一套安排
的支撑
整体资金判断
整体信号
主要风险
年的预计进账的
```

同时继续执行：不得虚构职业或收入来源、不得把命理判断写成已证实经历、不得在同一报告的不同可见区块重复关键整句。

## 边界

本阶段没有改变命盘计算、证据权重、年度选题和三年范围，也没有证明去年回看与真人经历相符。它解决的是“同一判断如何用完整、自然、可核对的中文表达”。年度进账正文、留钱正文、风险说明和行动建议的进一步口语化应作为下一批单独验收，不能把本次通过等同于整份报告已全部完成中文整改。
