# 财富通俗版 v3.13：年度标题可见去重验收

> 文案版本：`wealth-plain-v3.13`
> 标题规划版本：`wealth-headline-v3`
> 样本范围：固定命盘、边界命盘与合成夹具；这些样本用于回归测试，不代表真实准确率。
> 本批只调整年度标题的可见对象与句式，没有修改命盘计算、年度评分、主题选择、去年回看或年度正文。

## 问题根因

旧实现虽然为每个候选保留了不同的 `themeKey`，但可见核对对象只按 `order % 10` 取值。每条财富路径的九个语义主题因此被压缩成三个用户可见对象，导致不同年份、不同主题最终仍反复出现“到账时间”“共同用钱”等相近措辞。

本批把每条财富路径的九个主题分别映射到九个独立、职业中性的可见对象，并把同报告跨年标题的四个及以上连续汉字重复纳入预演阻断条件。去重判断现在针对用户看到的文字，而不是只检查内部主题键。

## 修改前后

- 修改前：预演样本中有 14 份报告出现跨年标题四字以上片段重复。
- 修改后：全部成功生成的固定、边界与合成样本均为 0 个可见片段重复警告。
- 保持不变：主题分布、年度强弱、证据选择和失败关闭规则。

## 代表样本

### R08：到账、投入回报、账面金额

- 2026：今年预计收到的钱较可能按计划到手。先比较预计与实际到账日期。
- 2027：今年新增投入带来的收入较可能同步提高。先比较相同投入能否再次产生进账。
- 2028：今年账面金额更容易真正收到。先记录账面金额最后能用的数额。

### R09：共同资金的三个不同问题

- 2026：今年分配共同资金较容易出现分歧。先逐项写清分配金额与额外开销。
- 2027：今年一起安排资金能让用钱更方便，但同时可能增加责任和花费。先写清共同承担的开销。
- 2028：今年与他人有关的资金责任可能增多，但负责范围容易说不清。先列出各自负责的部分。

### R11：结余、存钱进度、收支差额

- 2026：今年月底能留下的钱可能增多，但新增花费也可能消耗结余。先设好日常开销的最高金额。
- 2027：今年存钱进度有改善机会，但零散花费也会增加。先确认临时开销预留的金额。
- 2028：今年收支差额可能扩大，但花出去的钱也可能变多。先检查每月进账与支出记录。

## 验收边界

本批保证同一份成功生成的财富报告中，三个年度标题不会复用相同的四字以上核心片段。它不承诺所有报告之间完全不出现相同词语；当两个命盘命中相同主题、方向与强度时，跨报告仍允许输出相同结论，避免为了制造差异而随机改写或加入没有计算依据的情节。
