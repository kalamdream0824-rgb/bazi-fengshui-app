## 2. 财富浏览器主链路

专项脚本 `e2e/run_wealth_v3_e2e.py` 在真实 HTTP 和 MySQL 下完成以下检查：

- 注册新账号、真实排盘、生成财富通俗版并进入 v3 阅读页。
- 核对三年、五条钱路、留钱、年度比较和有依据才出现的风险内容。
- 刷新后正文和保存快照完全一致；返回“我的命书”后再次打开仍完全一致。
- 360、430、1280 三种宽度均无横向溢出，纸张与背景对齐。
- 仅用于界面边界的无风险合成契约样例不显示风险卡、占位文案或空白断层。
- 12 组完整出生测试输入逐份经真实接口生成，再从 MySQL 读取；13 份报告正文往返一致。
- 第二个账号看不到第一个账号的书架内容，直接读取报告返回 404。
- 浏览器控制台没有错误。

无风险页面使用合成契约样例只验证布局，不能冒充真实出生输入的引擎命中结果；其余 12 组 R01–R12 是完整出生测试输入，也不是消费者真实经历或现实准确率样本。

通用脚本 `e2e/run_e2e.py` 另行覆盖注册、排盘、单身/交往/已婚三种感情命书、书架回看、会员模拟购买、分享、历史、刷新兜底、退出登录和合规页面，共 35/35 通过。这说明财富 v3 接入没有破坏已有主链路。

## 3. 真实 MySQL 存储结果

实际环境：MySQL 8.4.11，服务端、数据库和 `content_json` 均为 `utf8mb4 / utf8mb4_unicode_ci`；`content_json` 是非空 `TEXT`。

任务账号共保存 13 份 `wealth-narrative-v3`：

| 指标 | 结果 |
|---|---|
| JSON 合法性 | 13/13 为合法 JSON |
| 内容结构 | 每份 `horizonYears = 3`、`years = 3`、`pathSummaries = 5` |
| 最小正文 | 26,846 UTF-8 字节 |
| 最大正文 | 51,559 UTF-8 字节 |
| 平均正文 | 42,760 UTF-8 字节 |
| 最大正文字符数 | 48,115 |
| 保存、接口返回、刷新、书架回看 | JSON 语义完全一致 |

必须直说：`TEXT` 的上限是 65,535 字节，当前最大样本已使用约 78.7%，只剩 13,976 字节。这个结果证明“当前 13 份三年测试报告能保存并回读”，不证明所有合法三年输入都不会越界，更不支持直接开放五年。

本任务按既定边界不修改表、不迁移数据。建议在扩大样本覆盖、增加年限或正式放量前，将 `content_json` 纳入正式数据库迁移改为 `MEDIUMTEXT`，并为序列化字节数增加自动上限测试和保存失败的稳定错误处理。旧计划里曾使用 `LONGTEXT`，当前实际 schema 已收窄为 `TEXT`，不能沿用旧计划的容量假设。

## 4. 结构化差异与基线

冻结文件 `wealth-v2-baseline-20260829.json` 的 SHA-256 仍为：

`37a756756434ef3ca9115b4812006dbf3d98489047dce78a6f79c8d422a62a2a`

`WealthV2BaselineTest` 和完整出生输入回归继续通过，说明原排盘、事实提取、路径分数和 v2 快照没有因 v3 页面或保存接入而被改写。差异只发生在独立的 v3 表达链路：

| 旧版问题 | v3 预期差异 | 未改变内容 |
|---|---|---|
| 排名第一就写成主要钱路 | 支持无主线、并列或仅相对领先 | 五路径原始评分 |
| 没有负向依据仍固定输出风险 | `risk = null` 时后端不造风险，前端不留空卡 | 原始正负依据 |
| 相同条件套不同年序剧情 | 按相邻年度真实依据比较；相同则写延续 | 年度事实和权重 |
| 通俗页暴露内部规则和分数 | 页面只展示审核后的阅读块 | 快照仍保留审计字段供核对 |
| 未知版本误套旧结构 | 明确提示不支持 | v1/v2 历史快照读取 |

因此没有批量更新 v2 冻结快照，也没有用“新文案看起来不同”掩盖计算变化。

## 5. 本轮发现并修正的验收缺口

1. **整改规范未进入默认后端回归。** 根因是 Surefire 默认不发现 `*Spec`；现已把标准测试命名和 `*Spec` 一并纳入默认入口。
2. **财富契约未进入 CI。** 现有 PR 工作流只跑前端测试、检查、构建和后端测试；已增加 22 项财富 v3 契约检查。
3. **Vite 代理目标写死 8080。** 这会让独立验收端口误连到旧 H2 服务；现支持 `VITE_API_TARGET` 覆盖，默认仍保持 `http://localhost:8080`。
4. **真实存储余量偏小。** 当前样本能保存，但 `TEXT` 容量安全不能判为彻底通过；已记录为正式放量前的 P1 数据库治理项，本任务未越权迁移现有库。
