# 偏弱内部状态 × 财富文案小批次样本 v1

> 批次目标：验证“同为偏弱”时，是否能根据根气和明透印星给出不同的阅读提示。
> 实施边界：正式旺衰仍为“偏弱”，不改财富路径评分、年度主题、标题规划和风险判断。

## 2. 前端可见变化

财富通俗版文案版本升级为 `wealth-plain-v3.7`。原有阅读说明保持不变，在末尾增加一条与内部状态对应的提示：

> 本报告按传统命理规则整理资金变化，不判断职业或收入来源，也不能替代现实中的收益与风险判断。观察事项只用于核对现实情况，不是预测成立的证明。

只有正式旺衰为“偏弱”时才追加上述三类提示；非偏弱命盘不追加。

## 3. 计算与输出边界

- `weakSupportProfile` 是偏弱档内部标签，不是新的正式旺衰等级。
- `natal.weak_support_profile` 会随财富年度事实输出，供文案层读取和后续审计。
- 该事实不生成评分证据，因此不会改变 `stable_income`、`skill_income`、`project_income`、`cooperation_income`、`retention` 五条路径的分数。
- 每年五条路径的顺序、决策、重点主题和标题仍由原财富规则产生。
- 已保存的旧报告不会被重新渲染；新生成报告使用 `wealth-plain-v3.7`。

## 4. 自动验收

六个样本锁定以下条件：

1. 六盘正式旺衰均保持“偏弱”；
2. 三种内部状态各有两个独立命盘；
3. 正式粗分不变，影子分只记录根气差异；
4. 财富报告包含内部状态事实，但评分证据不得引用该事实；
5. 六盘都能得到对应提示，文案版本固定为 `wealth-plain-v3.7`。

运行：

```bash
cd apps/server
./mvnw -q -Dtest=ReportAnalysisSupportProfileTest,WeakSupportProfileCorpusTest,WealthWeakSupportCopyTest test
```

## 5. 当前结论

这批改造解决的是“同为偏弱却完全使用同一承载说明”的问题，不解决年度财富主题重复或现实事件命中率问题。后两者仍需要分别依靠标题/主题去重验收和真实用户盲测，不能把内部状态标签当成准确率已经提升的证据。
