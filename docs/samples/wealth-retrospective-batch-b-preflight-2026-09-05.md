## 选择规则及边界

1. 主要对象：支持权重与限制权重之和降序 → 净权重绝对值降序 → 证据具体度降序 → 固定对象顺序。
2. 证据具体度仅作为并列顺序：流年 > 大运 > 原局组合 > 原局单项。数字 4/3/2/1 是序位，不作为新分数与权重相加。
3. 最终对象并列顺序：收支结余、进账持续性、投入回报、到账节奏、资金责任。这是确定展示次序，不代表哪类财富机会更好。
4. 对象内部角度：该角度证据绝对权重之和降序 → 证据具体度 → angle key 字典序。
5. 次判断选择其他对象且使用不同角度。隐性影响优先选择结余，再考虑现有 risk 指向的限制证据、资金责任、到账节奏及其他对象，并执行角度与根事实去重。
6. 无证据或来源未解析的路径不能成为肯定判断。来源未解析的证据仍保留在提取结果中供审计。无法填满的槽位以内部 `empty/partial` 状态明确表达，不抛新增用户业务错误，不虚构三个结论。
7. 该排序是可追溯的规则设计，尚未经真实用户反馈校准。批次 C 的文案必须根据实际证据角度表达，不得将原局背景直接写成去年已发生的具体事件。

## 签名定义

计划版本、年份、各槽位的 subject/direction/strength/angle、全部引用与主引用进入 SHA-256。每条引用包括 path、ruleKey、factKey、family、带符号权重及根事实 kind/code/value；集合排序去重。技术 ID 用于追溯，不进入语义签名，姓名、用户 ID、当前时间不参与。

签名变化表示计划或引用发生变化；它不是准确率、文本多样性指标或选句随机种子。批次 C/D 还必须直接比较最终用户可见段落。
