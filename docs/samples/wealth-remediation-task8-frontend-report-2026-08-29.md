## 1. 本次解决的问题

任务 7 后，新生成的财富报告已经是 v3 结构，但前端只认识 v2。若直接读取，页面既不能正确解释结构化文字块，也可能把未知版本误套到旧事业阅读页；“我的命书”列表还会把 v3 的 `thesis` 对象当成文字渲染并报错。

本任务没有把 v3 压回 v2 的“主要钱路、辅助钱路、固定风险”三卡模型，而是按后端已保存的语义独立展示：

- 没有突出方向时，不补一个“最旺钱路”。
- 多个方向并列时，显示“可以一起关注的方向”。
- 相对领先时，只显示“相对更值得关注的方向”，不升级成必然机会。
- 没有负向依据时，不渲染风险卡、空占位或“暂无风险”。
- 现实观察使用“可以留意的现实情况”，不包装成预测成立的验证条件。

## 2. 页面结果

### 命书正文

新增 v3 独立阅读组件，按以下顺序展示保存快照：

1. 三年总览与摘要。
2. 稳定收入、靠能力赚钱、项目和额外收入、合作带来的收入、把钱留下五条钱路。
3. 每年的总判断、相对方向、收入说明、留钱说明。
4. 有真实负向依据时才出现的提醒。
5. 现实观察、可以执行的行动、与下一年的实际比较。
6. 三年安排和阅读边界。

通俗页不直接展示 `facts`、`evidence`、`decisions`、净分、规则键或内部版本标签。这些字段继续保存在快照中供后端核对，但不会污染普通用户阅读。

### 版本分流

- `wealth-narrative-v3` 使用新组件。
- `wealth-narrative-v2` 保持原组件和原快照语义。
- 事业、财富 v1、感情 v1 和单身版继续按各自旧组件读取。
- 未知版本显示“暂不支持读取这份命书”，不再默认进入事业组件。

### 我的命书

列表标题同时兼容旧版字符串 `thesis` 和 v3 结构化文字块，v3 报告可以正常显示标题并进入对应正文。

### 视觉

页面没有重新设计整站，继续沿用现有的深墨夜空、月白账册纸面和朱批年度时间轨。新增样式只用于区分并列/相对领先、留钱、真实提醒、现实观察、行动和年度比较；风险为空时对应节点根本不生成，因此不会留下多余间距。

## 3. 测试驱动记录

- 未知版本会误套事业阅读结构。

- 并列和相对领先缺少中性表达。
