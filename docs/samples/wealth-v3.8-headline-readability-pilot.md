# 财富 v3.8 年度标题中文可读性样本

> 范围：只改财富通俗版的年度标题。
> 未改：去年回看、年度进账正文、留钱正文、风险、观察事项、行动建议。
> 版本：`wealth-plain-v3.8` + `wealth-headline-v2`。

## 改造规则

每个标题先形成结构化语义：

```text
明确对象 + 判断方向 + 限制（如有）+ 现实核对动作
```

输出固定为两个完整句子：

```text
今年……。先……。
```

生成器会拒绝“有利条件、好坏条件、改善空间、存在变数、有变数、值得重点留意、同时记录、这方面、先观察再判断”等抽象拼接词。

## 当前结论

相较 v3.7，年度标题已经从抽象短语拼接变为完整判断，语法和指代问题明显减少。同一语义主题仍保持相同文字，没有通过随机同义词制造虚假差异。

这只是标题层通过，不代表整份报告已经完成中文整改。下一阶段需要把同样的语义结构应用到“去年回看”和“年度比较”，这两个区块目前仍包含“有利条件比上年多”“这方面可能有进展”等抽象表达。
