## 5.5 新人解读引擎（方案 B · 已交付）

### 5.5.1 目标与边界

- 目标：让**没接触过命理的新人**看完排盘结果、专业细盘后，能大致明白「这张盘在说什么」，而不是面对四柱表/十神/神煞发懵。
- 边界（合规红线，必须遵守）：只做**结构解释与性格倾向参考**，不做结论性预测；不出现"你今年会发财/会离婚/何时结婚"类断言；每段保留"传统命理框架下的文化参考"语气。
- 范围：基本排盘页（/chart）+ 专业细盘页（/chart/pro）；合婚/命书/运势暂不纳入（避免结论性内容合规风险）。

### 5.5.2 输出结构

`lib/explainer.ts`：输入 `PaipanResult`（+ gender），输出：

```ts
interface ExplainPoint { label: string; text: string }
interface ExplainBlock {
  title: string          // 如「日主与五行」
  points: ExplainPoint[] // 2-4 条要点，每条 = 术语 + 一句人话
}
interface ChartExplanation {
  overview: string[]     // 2-3 句总览（页面顶部）
  blocks: ExplainBlock[] // 分块解读（可折叠）
}
```

### 5.5.3 解读内容清单

| 块 | 数据来源 | 人话要点 |
|---|---|---|
| 日主与五行 | 日柱天干、`wuXing` | 日主是什么（如"壬水"→江河之水，传统多与流动/灵活相连）；五行旺缺对应的倾向参考 |
| 四柱定位 | `pillars` | 年柱（祖上/早年）、月柱（成长环境）、日柱（自身/婚姻）、时柱（晚年/子女）在传统框架里的定位，一句带过 |
| 十神性格 | `pillars.*.shiShen` | 日主十神（正财/偏印等）的通俗解释；四柱十神整体一句概括 |
| 神煞参考 | `shenSha` | 命局出现的神煞每个一句通俗说法（如天乙贵人：传统称遇事多助力），强调参考 |
| 当前大运 | `daYun[isCurrent]` | 当前处于哪个十年运、传统上该运侧重什么（参考） |
| 流年 | `currentLiuNian` | 今年干支、传统框架下通常怎么理解（参考，不预测具体事件） |

### 5.5.4 术语词库（BaziTable TIPS 扩展）

现有词条仅 5 条（主星/藏干/纳音/星运/神煞），扩展为：

- 基础：天干、地支、五行、日主（出生日的天干代表自己）；
- 十神全称 10 条：正官/七杀/正印/偏印/比肩/劫财/食神/伤官/正财/偏财，各一句通俗解释；
- 结构：大运、流年、十二长生（星运）、藏干；
- 已有 5 条保留并润色。

### 5.5.5 文案样例（1995-10-08 14:30 男命：乙亥 乙酉 壬申 丁未）

> **总览**：你的日主是壬水——命理传统上壬水与江河、流动、开阔相连，多与灵活和包容的性格倾向相关。五行中金偏旺、火偏弱，通常被解读为思辨力强、行动上偏稳健的组合。以下内容均为传统命理框架下的文化参考，不作人生断言。
>
> **十神性格**：日柱坐"正财"，传统解读偏重视实际、重积累的倾向；年柱"伤官"多与表达欲、创造力相关。这些只是倾向参考，不构成对你的评价。

### 5.5.6 合规模板与禁用

- 每段解读开头或结尾带"传统命理框架下……仅作文化参考"；
- 禁用词：一定、必定、注定、今年会发财、会离婚、能活到、克夫/克妻 等结论性断言；
- 不做医疗/投资/婚姻等确定性建议；
- 无命盘（未排盘）时不生成解读。

### 5.5.7 测试计划

- `explainer.test.ts`：固定 fixtures 输入 → 断言总览含日主五行、五行旺缺文本；神煞/十神词条覆盖；含"参考"合规词；不含禁用断言词。
- 组件测试：`/chart` 渲染解读卡、`/chart/pro` 各页签渲染对应解读块；释义点击可弹词条。
