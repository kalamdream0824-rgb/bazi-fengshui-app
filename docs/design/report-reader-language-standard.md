# 命书通俗版语言标准

## 目标口吻

通俗版采用“日常、直接、但稳重”的表达：像一个懂行的人当面把事情说明白，不像工作汇报，也不写成聊天段子。

专业版可以在折叠的“专业依据”中保留规则键、命理术语和证据；主结论仍必须让普通读者直接看懂。

## 固定结构

报告年限由主题产品配置决定，当前允许二至五年。事业版当前输出两年；财富通俗版对外固定三年；技术层预留五年但前端不提供年限选择。

每个主题都按同一顺序输出：

1. 先用一句话说明本主题配置年限内的重点。
2. 每年只说一个主要判断。
3. 用两条普通话解释为什么。
4. 说明眼下最需要解决的具体问题。
5. 只给两件可以马上去做的事。
6. 说明出现什么情况时需要换做法。

财富 v2 在逐年内容前增加“五条钱路”概览，必须同时展示稳定收入、靠能力赚钱、项目和额外收入、合作带来的收入、把钱留下，并区分主要方向、辅助方向和主要风险。该概览不能替代逐年主判断。

## 写作红线

- 一句话尽量不超过 48 个汉字。
- 优先使用“工作、工资、职位、简历、面试、客户、收入、作品、休息”等普通词。
- 通俗正文避免“权责、正式授权、评价周期、资源配置、协作节点、交付、兑现、承接、责任边界、复盘”等报告腔。
- 不写“可能存在一定影响”“现有证据不足”“先观察再判断”一类无答案句子。
- 不用随机同义词制造个性化；事业现实问卷只改变场景说法，不改变命理证据。财富 v2 已移除现实问卷，问卷答案不得影响证据、排序或文案。
- 建议必须能直接执行，不能只写“保持谨慎”“把握机会”“提升自己”。
- 每个判断都必须交代对象，例如写“求职进展不顺”，不能只写“现在卡住了”。
- 原因句必须至少回答一个具体问题：什么事情不顺、问题可能出在哪里，或者下一步看什么结果。
- 状态摘要可以简短，但不能直接拼接“最近很累”“正在改变”等缺少对象的问卷标签。

## 改写示例

| 不采用 | 采用 |
|---|---|
| 今年先把成果和责任边界做实，明年再争取正式授权。 | 今年先把手上的成绩做出来，明年再找机会谈晋升。 |
| 提高岗位匹配度，不要增加投递数量。 | 简历要投得准，不要只是投得多。 |
| 核对项目成本和交付范围。 | 接项目前先说清价格、时间和要做到什么程度。 |
| 当负荷影响恢复时控制扩张。 | 如果累到影响睡眠和工作，就先减掉一部分事情。 |
| 现在卡住了，先找清楚原因。 | 目前求职进展不顺，先看看问题出在求职方向、简历，还是面试表现。 |
| 当前卡点 | 眼下最需要解决的问题 |

## 后续主题验收

综合、事业、财富、感情主题开放页面报告前，必须复用以上结构、禁用词和句长测试。主题可以更换普通词汇，但不能降低直白程度。主题配置可在二至五年之间变化，但每年仍只能有一个主焦点，并必须说明与前后年度的关系。
