## 1. 定位与目标

产品同时服务两类用户：

- **大众用户**：用免费排盘 + 温和解读引流，靠易用性和内容获得感留存，转化为会员或单次付费；
- **命理爱好者/进阶用户**：专业细盘深度内容形成粘性，是命书、合婚报告、年卡会员的高意向人群。

商业模式 = **免费工具引流 + 会员订阅 + 单次内容付费**。不碰广告、不做真人算命咨询（合规风险高、客单价无规模优势）。

## 2. 免费 / 付费边界

> 原则：**盘面数据免费、内容类付费**——「看盘」是工具，「深度解读与可保存报告」是服务。专业细盘结构数据不整页锁死；会员有效期内解锁站内已上线的数字付费内容。

### 2.1 命书权益规则（已确认）

- 付费命书分为**通俗版**与**专业版**两个独立商品，购买时二选一；后续购买另一版本需重新付费。
- 每个「命盘 × 版本 × 关注主题」是一份独立报告；更换任一项均视为新报告。
- 非会员可不限次数单独购买新报告；这里的“不限次数”不是一次付费无限生成。
- 会员每天可免费成功生成 3 份新报告，按北京时间自然日计算；生成失败不占额度。
- 会员用完当日 3 份额度后，可继续按单次价格购买，不阻断生成入口。
- 已成功生成的报告永久归用户，可自由重复下载；下载已有报告不占会员额度，会员到期后仍可下载。
- 会员权益表述为“会员有效期内解锁站内已上线的数字付费内容”；真人咨询、实体商品等未来非数字服务不自动包含。

## 3. 盈利点分层

### 3.1 会员订阅（主力）

- 套餐（建议稿，待定价确认）：**30 天 ¥29.9 / 90 天 ¥68 / 365 天 ¥198**
  - 年卡用于拉高 LTV；季卡作为主推锚点（对比年卡显得划算）；
  - 金额只由后端 `MemberPlans` 常量控制，前端只展示，已有实现无需改结构。
- 会员权益：有效期内解锁站内已上线的数字付费内容；命书每日最多免费成功生成 3 份，超额可单次付费；已生成报告永久下载。

### 3.2.1 命书双版本内容边界

| 维度 | 通俗版 | 专业版 |
|---|---|---|
| 面向用户 | 普通用户 | 命理从业者、进阶爱好者 |
| 表达 | 术语翻译、重点摘要、生活化说明 | 保留专业术语、取法过程、规则证据与流派说明 |
| 数据密度 | 精简图表与关键证据 | 完整四柱、藏干、副星、空亡、神煞、大运细表 |
| 目标篇幅 | 10–14 页 | 16–22 页 |
| 技术原则 | 与专业版共用同一套命盘证据 | 不得仅通过晦涩措辞冒充专业深度 |

两版共用一套规则引擎，由结构化证据派生不同表达；不得维护两套互相独立、可能结论冲突的命理逻辑。

### 3.3 兑换码 / 礼品卡（冷启动渠道，零资质依赖）

- 基建已就绪（`bazi_redeem_code` + 兑换接口），**无需等真实支付即可变现**；
- 用途：社群/电商/自媒体渠道分销（渠道折扣 7-8 折）、活动赠送、礼品卡；
- 需要补的只有运营侧的批量生成/查询接口（P2 待办）。

## 4. 定价策略要点

1. **盘面数据全免费（引流 + 留存），内容类设闸**：排盘与专业细盘结构数据全免费，解读只给少量条数做钩子，深度内容与报告付费；
2. **命书作为首个付费验证点**：通俗版 ¥6.9、专业版 ¥12.9，先以低决策成本验证内容价值；
3. **会员价值锚在「全部数字内容 + 每日 3 份命书」**，超额仍可单次付费；
4. 上线后按转化数据调整：会员购买率 <1% 说明免费给多了；>5% 说明免费钩子不足，需收紧。

## 5. 合规口径（付费文案强制规范）

> 已有红线（`dev-checklist.md` / 前端设计文档）：文案「温和参考」、不绝对预测、保留免责声明；不做医疗/投资/婚姻等确定性建议。付费场景下**更严**，宣传即合规审查对象。

**可用词**：文化参考、传统命理框架、仅供参考、性格倾向、经典意象、民俗文化。

**禁用词**：改运、消灾、转运、必发财、必离婚、很准、灵验、预测命中、帮你避开灾祸。

**付费页文案模板（可直接复用）**：

- 标题：`读懂你的命盘：专业细盘 + 深度解读`
- 副标题：`传统命理框架下的文化参考，帮你看清格局与运程的经典解读方式`
- 会员权益卡：`站内数字付费内容 · 每日 3 份命书 · 已生成报告永久下载`
- 额度用尽提示：`今日会员免费额度已用完（3/3）。继续生成本份「{版本}命书」需单独支付 {价格}，生成后可永久下载。`
- 底部免责：`本服务内容基于传统命理文化整理，仅供娱乐与参考，不构成任何人生、医疗、投资或法律建议。`

## 6. 落地路径（实现顺序）

| 步骤 | 内容 | 依赖 |
|---|---|---|
| 1 | 文字型命书样本：统一证据引擎 + 通俗/专业双表达 + 五章 PDF | 内容规则与人工审阅 |
| 2 | 报告资产：生成记录、永久下载、用户隔离、会员每日 3 份计数 | 步骤 1 |
| 3 | 单次付费：通俗 ¥6.9 / 专业 ¥12.9；会员超额提示与继续购买 | 步骤 2；先复用模拟支付 |
| 4 | 合婚报告 / 择日报告商品化 | 步骤 3 的支付与权益链路复用 |
| 5 | 兑换码批量管理接口（P2）+ 渠道冷启动 | 后端小活 |
| 6 | 真实支付接入（微信/支付宝） | **企业资质 + 商户号 + 备案域名** |

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 合规审查（内容平台下架/处罚） | 付费文案走第 5 节模板；上线前人工过一遍全部付费页文案；保留完整免责声明 |
| 免费→付费转化率低 | 通俗 ¥6.9 / 专业 ¥12.9 先验证；按版本、主题分别统计转化 |
| 支付资质未就绪 | 兑换码渠道先行变现；模拟支付保留为演示 |
| 会员权益被绕过 | 后端接口校验权益（不依赖前端隐藏）；关键数据接口会员专属 |
| 会员额度并发绕过 | 后端事务内锁定用户并分配当日 1–3 额度槽；失败生成释放额度 |
| 双版本内容趋同 | 同一证据引擎、两套表达验收标准；专业版必须展示方法和证据链 |
