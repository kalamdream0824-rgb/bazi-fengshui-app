# 朱墨星图 —— 产品视觉哲学

**朱墨星图**：以朱砂为气，以墨线为骨，以留白为呼吸。这不是一套皮肤，而是一种看待命理工具的方式——屏幕是一张星图，信息是一颗颗星，唯有克制的朱砂点，才能让命盘在纸上发出光来。

空间的本质是“呼吸”。每一个页面都遵循八点网格与对称律动：按钮成组时等宽同高，卡片成列时边距一致，标题与内容的间距永远大于内容与内容的间距。留白不是空白，是墨色停下来的地方；用户应该能在一屏之内感到安定，而不是被信息追赶。

色彩来自材料本身：宣纸的暖白承载一切，松烟墨的深褐书写主体，朱砂红只在“此刻重要”的地方出现——日主、当前大运、主行动按钮——像印章盖在关键处。金线是边界而非装饰，一像素的描金让器物显得被细细镶过；青玉色仅用于“吉、宜、生”的轻声提示。整个色盘不超过六色，因为星图越干净，星辰越亮。

层级即秩序。一张屏幕只讲一件事：首页讲“今天”，排盘页讲“这一盘”，细盘页讲“这十年”。字号阶梯收敛为三档——宋体大字承载干支，正文承载说明，小字只做注脚。字距与行距经过校准，让“密”的地方密得有理（四柱表），让“疏”的地方疏得从容（命书封面）。

时间也是设计的一部分。按压有回弹，切换如翻页，释义像从纸下抽出的一张笺纸。所有动效短于三百毫秒，克制、顺滑，并尊重系统的“减弱动态”偏好——因为对一张星图来说，静默本身就是一种语法。

最终的标准只有一条：每一屏都要像一位老师傅在灯下逐格校过——边距无可指摘，对称无可动摇，朱砂不多落一笔，金线不虚走一毫。它应当让使用它的人感到，这个器物是被认真做出来的，值得被认真对待。
