# 经典命例兼容测试 v2

> 状态：已完成首轮扩容与分区
> 语料：8 例、4 组成对比较
> 结论：校准区 3/3 方向兼容；隔离评估区 0/1，发现 1 项明确缺口

## 1. 本阶段解决什么问题

v1 只有一组成对命例，无法判断测试是否只是偶然命中。v2 将命例拆成两个物理文件：

- `CALIBRATION`：6 例、3 组，用于固定当前已经能够表达的结构关系；
- `HOLDOUT`：2 例、1 组，在先记录原文方向后运行引擎，用于暴露未覆盖能力。

通过测试仍然只代表“当前规则与所引传统结构判断相容”，不代表人物经历真实，也不代表预测准确。

## 2. 校准区结果

| 比较维度 | 较低命例 | 较高命例 | 当前分数 | 状态 |
|---|---|---|---|---|
| 湿土缓火与火支增势 | 癸丑·戊午·丙午·壬辰 | 癸巳·戊午·丙午·壬辰 | 3.0 < 4.0 | `MATCH` |
| 日坐财与日坐印根 | 己亥·丙寅·戊子·甲寅 | 戊子·甲寅·戊午·甲寅 | 1.5 < 2.0 | `MATCH` |
| 同类时干是否出现 | 己卯·丁卯·壬午·甲辰 | 己卯·丁卯·壬午·癸卯 | 0.0 < 1.0 | `MATCH` |

第三组只比较日主生扶粗分。分数增加不等于整体更吉；原文恰恰将额外癸水描述为财富结构中的竞争因素。

## 3. 隔离评估区结果

来源先记录的相对判断：

```text
戊申·癸亥·丙午·壬辰
  <
戊午·癸亥·丙戌·壬辰
```

《滴天髓阐微》在后例中强调年支午火帮助冬生丙火，并称其结构“稍胜前造”。当前引擎却给两例相同的 1.0 分。

登记缺口：

- 代码：`BALANCE_POSITION_WEIGHT_COLLISION`
- 原因：当前算法把年支午火与日支午火都固定计为 `+1`；
- 未表达：月令背景下不同位置的根气、远近、坐支以及组合关系；
- 影响：五行数量相近但位置不同的命盘，可能被压成同一旺衰结果。

这项失败不能靠增加同义文案解决，也不应该通过修改命例预期消除。

## 4. 防止“改几版仍无效果”的机制

每组成对比较同时保存：

- `sourceExpectedRelation`：原文方向；
- `observedEngineRelation`：当前实测方向；
- `engineCompatibility`：由前两者自动推导；
- `gapCode` / `gapReason`：未命中时的原因。

测试会精确区分 `LOWER_THAN`、`EQUAL` 和 `GREATER_THAN`。如果算法从“同分”恶化成“方向相反”，测试同样失败；如果以后修复为正确方向，测试也会要求人工复核并更新已知缺口状态，不能静默改写历史。

隔离文件声明 `SOURCE_FIRST_NO_RETROACTIVE_RELABEL`：禁止为了提高兼容率把失败案例移入校准区，或事后改写来源方向。

## 6. 必须说明的限制

当前 `HOLDOUT` 是仓库内的隔离评估集，不是真正意义上的外部盲测：开发者仍能看到四柱和预期。真正的盲测需要由独立人员保管未公开命例，或在受控 CI 中解封。

当前全部来源仍为公开数字转录，可信等级是 `C`。它适合检查规则兼容性，不适合计算现实预测准确率。

## 7. 根气影子评分实施结果

本阶段已在 `ReportAnalysis` 中加入 `rootedSupportScore`，但暂不接管正式旺衰等级。计算规则保持克制：

1. 以原有旺衰粗分为基础；
2. 如果某地支主五行已经生扶日主，不重复加分；
3. 如果主五行不生扶，但藏干中存在同类或印星，记为一处“二级根气”；
4. 每个地支最多增加 `0.1`，防止藏干数量直接放大分数；
5. 每次增加都写入 `rootedSupport` 证据，例如“戌藏丁二级根气+0.1”。

隔离组结果由：

```text
正式粗分：1.0 = 1.0
```

变为：

```text
根气影子分：1.2 < 1.3
```

来源方向得到区分，同时两例正式等级仍为“偏弱”。现有年度规则、财富基线和已保存报告契约没有切换到影子分。

## 8. 固定样本批量影子审计

已对财富基线中的 R01–R12 运行根气影子评分，审计结果冻结在
`rooted-support-shadow-audit-v1.json`。这里的“跨档”只是按现行阈值投影，正式输出仍使用旧分数与旧等级。

| 指标 | 结果 |
|---|---:|
| 输入记录 | 12 |
| 独立四柱 | 11 |
| 影子分发生变化 | 7 / 12 |
| 按旧阈值投影后跨档 | 1 / 12 |
| 可能受影响的四主题年度内容 | 10–11 个主题年 |
| 平均增量 | 0.092 |
| 最大增量 | 0.3 |

12 条输入不等于 12 个独立命盘：R01 与 R02 四柱相同，只有性别不同。因此本批次只能作为小样本工程审计，不能当成准确率证据。

唯一跨档样本是 R05：

```text
四柱：壬申·丁未·乙未·己卯
正式粗分：1.5（偏弱）
影子评分：1.8（按旧阈值投影为中和）
增量来源：年支申藏壬、月支未藏乙、日支未藏乙，各 +0.1
```

若直接启用影子分，R05 的四个主题共 10–11 个主题年可能改走另一套规则分支：单身感情版为 2 年，交往或已婚版为 3 年。这个影响不是文案级变化，因此当前不能直接切换生产评分。

R05 已完成人工复核，详细记录见 `r05-rooted-support-manual-review-v1.md`。复核结论为“偏弱（有根）”，不接受仅因影子分跨过旧阈值便直接改判“中和”。

## 9. 当前结论与下一项改造建议

根气影子分已经证明能够区分原算法压平的结构，但 `0.1` 权重和现行分档阈值尚未完成校准。下一步应当：

1. 扩充独立样本，重点覆盖旧分数 `1.0–2.0` 和 `3.5–4.5` 的分档边界；
2. 对所有跨档样本比较四主题正文变化，而不只比较分数；
3. 统计跨档比例和明显不符率后，再决定调整权重、调整阈值，或让影子分接管正式等级。

在上述证据完成前，`rootedSupportScore` 只用于影子审计，不能接管正式旺衰等级。
