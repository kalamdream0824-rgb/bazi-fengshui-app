# R05 根气影子评分人工复核 v1

> 复核对象：R05（女，1992-07-18 06:15，广东省广州市）
> 四柱：壬申 · 丁未 · 乙未 · 己卯
> 结论：保留“偏弱”，增加“有根”修饰；不接受直接改判“中和”

## 1. 先确认输入链路

原固定样本只写了“广州”，不符合当前真太阳时地点库要求的“省份 + 城市”格式。人工复核改用产品可提交的规范值“广东省 广州市”，但没有改写原始基线样本。

| 项目 | 结果 |
|---|---|
| 原始钟表时间 | 1992-07-18 06:15 |
| 真太阳时 | 1992-07-18 05:41 |
| 经度时差 | -27 分钟 |
| 均时差 | -6.1 分钟 |
| 时辰边界是否变化 | 否，仍为卯时 |
| 四柱是否变化 | 否，仍为壬申·丁未·乙未·己卯 |

因此，本次旺衰复核不存在“地点校正后换了时柱”的干扰；但固定样本地址格式需要在后续语料治理中统一。

## 2. 为什么不能只看 1.5 → 1.8

当前基础粗分由两项组成：时支卯直接生扶 `+1`，年干壬生扶 `+0.5`，合计 `1.5`。影子层又发现三处藏干支持：申中壬、月支未中乙、日支未中乙，各 `+0.1`，得到 `1.8`。

问题在于，`1.8` 超过旧阈值 `1.5` 只是数学跨线，不等于结构已经由偏弱变成中和。影子算法只增加支持分，没有同步量化月令、泄耗、财星重量、藏干位置和组合条件；拿一个单向加分结果直接改档，会系统性高估临界命盘。

## 3. 人工结构复核

支持日主的因素：

- 时支卯是乙木直接根气，不能把该命盘判断成“完全无根”；
- 年干壬为明透印星，申中另藏壬水；
- 月支未、日支未都藏乙，说明乙木并非全无内在支持。

限制日主的因素：

- 乙木生于未月，月令不直接生扶；
- 月干丁明透，两个未中又藏丁，存在持续泄木；
- 两个未以己土为主气，时干再透己，财星负荷明显；
- 申中藏庚，对乙木形成约束。

古籍相近结构也同时强调两面：《滴天髓阐微》所载“丁亥·丁未·乙亥·己卯”命例，先指出乙木生未月处于休囚、丁火泄气，又强调时支卯通根及亥水生扶的补救作用。这支持“未月乙木要同时审查泄耗和根印”，并不支持“只要发现藏根就自动升为中和”。

## 4. 人工结论

| 项目 | 决定 |
|---|---|
| 正式旺衰等级 | 保留“偏弱” |
| 结构修饰 | “有根、有印，不按无依处理” |
| 影子分用途 | 只作为偏弱档内部的强弱修饰 |
| 是否启用 1.8 对应的“中和”规则 | 否 |
| 建议代码策略 | `KEEP_SERVING_BAND_USE_ROOT_AS_MODIFIER` |

适合面向用户的表达不是“承载能力很弱”，也不是“整体中和”，而是：

> 自身有一定支撑，遇到合适条件能够推进事情，但同时承担太多目标时仍容易吃力，宜先保证基础和余量。

## 5. 如果误改为“中和”，会发生什么

这不是一个标签替换，而会改变规则资格：

- 综合：偏弱时的负荷限制会变成中和支持，输出、财富年份可改走推进型规则；
- 事业：输出、财富、责任年份的基线可能从“谨慎承接”改成“主动推进”；
- 财富：会新增“财富存在且承载不弱”，并在财富年份移除 `-3` 的留存限制；
- 感情：当前专用感情计算只保存旺衰等级，尚未用它参与关系维度打分，因此通常不发生直接变化。

产品实际年限合计为：事业 2 年、财富 3 年、综合 3 年、单身感情 2 年或交往/已婚感情 3 年。因此一个跨档命盘的最大影响范围是 `10–11` 个主题年，而不是固定 10 个。

## 6. 验收方式

运行：

```bash
cd apps/server
./mvnw -q -Dtest=R05RootedSupportManualReviewTest,RootedSupportShadowAuditTest test
```

专项测试锁定以下事实：

1. 规范出生地点可以完成真太阳时校正；
2. 校正前后四柱不变；
3. 正式分为 `1.5`，影子分为 `1.8`；
4. 人工决策为“偏弱（有根）”，不切换正式分档。

## 7. 复核边界

本结论是“传统命理规则兼容性 + 工程风险”的人工复核，不是对现实人生事件准确率的科学证明。单个命例也不能用于校准全局阈值；下一阶段仍需补充更多 `1.0–2.0` 附近的独立命盘，并由第二位复核者盲审。
